# Ilhas de Éter — Protótipo 0.1

Jogo de RPG de aventura para navegador, em um único arquivo HTML, com visual 2.5D simulado em Canvas. Feito para testar no celular e no computador.

## Como jogar
- Movimento: WASD ou setas no teclado; no celular, use o direcional na tela.
- Atacar: Espaço no teclado ou botão **Atacar**.
- Rajada de Éter: E no teclado ou botão **Poder**. Custa 18 de energia.
- Esquiva: Shift ou botão **Esquiva**.
- Descansar/usar poção: H ou botão **Descansar**.
- Inventário: I ou botão **Inventário**.
- Esc: pausa.

## Publicar no GitHub Pages pelo celular
1. Crie um repositório novo no GitHub.
2. Envie `index.html` para a raiz do repositório (o README é opcional).
3. Abra **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Escolha a branch `main` e a pasta `/(root)`, depois salve.
6. Aguarde a publicação e abra o endereço que o GitHub mostrar.

O progresso é salvo no armazenamento local do navegador do aparelho. Se limpar os dados do navegador, o progresso pode ser perdido.

## Estado do protótipo
Inclui movimento, combate, inimigos que perseguem, XP e níveis, energia, poção, missão inicial, chefe, inventário simples e salvamento local. É um protótipo inicial: os próximos passos são balanceamento, mais mapas, áudio, animações, inventário/equipamentos e testes em aparelhos diferentes.
